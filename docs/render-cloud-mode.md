# Render Cloud Mode

Cognitive OS runs on [Render](https://render.com) as a cloud deployment.
The Render free tier is used with a persistent disk for data that must
survive restarts.

## Quick start

1. Deploy `master` branch via `render.yaml` (Blueprint deploy).
2. Add a **persistent disk** at `/var/data/cognitive-os` (1 GB is plenty).
3. Set `DATA_DIR=/var/data/cognitive-os` in Render environment variables.
4. Set `RENDER_ADMIN_IMPORT_ENABLED=true` and generate a strong
   `RENDER_ADMIN_IMPORT_TOKEN`.
5. Deploy and open `https://cognitive-os.onrender.com`.

## Persistent disk

Everything under `/var/data/cognitive-os` is persisted across deploys and
restarts.  The following files live there:

| File | Env var | Source |
|------|---------|--------|
| `state_snapshot.json` | `SNAPSHOT_PATH` | Auto-generated by the app |
| `cognitive_os.db` | `DATABASE_URL` | Auto-generated by SQLite |
| `jwxt_cookies.json` | `JWXT_COOKIES_PATH` | Import from local |
| `chaoxing_state.json` | `CHAOXING_STATE_FILE` | Import from local |
| `google_token.json` | `GOOGLE_CALENDAR_TOKEN_PATH` | Import from local |
| `google_credentials.json` | `GOOGLE_CALENDAR_CREDENTIALS_PATH` | Secret File or import |

When `DATA_DIR` is set to the Render mount path, the app automatically
re-bases all default `data/…` paths to the persistent disk.

Locally, leave `DATA_DIR=data` (the default) — nothing changes.

## Importing local state files

State files generated locally (cookies, tokens) must be uploaded to the
Render persistent disk.  Use the admin import API:

```bash
# Set RENDER_ADMIN_IMPORT_ENABLED=true and RENDER_ADMIN_IMPORT_TOKEN first

# JWXT cookies
curl -X POST https://cognitive-os.onrender.com/api/web/admin/import \
  -H "Content-Type: application/json" \
  -H "X-Admin-Token: $RENDER_ADMIN_IMPORT_TOKEN" \
  -d "{\"kind\":\"jwxt_cookies\", \"data\": $(cat data/jwxt_cookies.json)}"

# Chaoxing state
curl -X POST https://cognitive-os.onrender.com/api/web/admin/import \
  -H "Content-Type: application/json" \
  -H "X-Admin-Token: $RENDER_ADMIN_IMPORT_TOKEN" \
  -d "{\"kind\":\"chaoxing_state\", \"data\": $(cat data/chaoxing_state.json)}"

# Google token
curl -X POST https://cognitive-os.onrender.com/api/web/admin/import \
  -H "Content-Type: application/json" \
  -H "X-Admin-Token: $RENDER_ADMIN_IMPORT_TOKEN" \
  -d "{\"kind\":\"google_token\", \"data\": $(cat data/google_token.json)}"
```

Alternatively, set the JSON directly as Render environment variables:
- `JWXT_COOKIES_JSON` — JWXT cookie array (from `data/jwxt_cookies.json`)
- `CHAOXING_STATE_FILE` — already a path; place file on disk via Render Shell
- `GOOGLE_CALENDAR_CREDENTIALS_JSON` — full credentials JSON
- `GOOGLE_CALENDAR_TOKEN_JSON` — full token JSON

## Google Calendar

- Place Desktop OAuth credentials on Render as a **Secret File** mounted
  at `/etc/secrets/google_credentials.json`, or import via the admin API.
- Run `scripts/google_calendar_login.py` locally first to generate a token.
- Upload the token file via the admin import API or set
  `GOOGLE_CALENDAR_TOKEN_JSON` as an env var.
- Write operations still require an **accepted proposal** in the Web UI.
- Set `GOOGLE_CALENDAR_TIMEZONE=Asia/Shanghai` for UTC+8 display.

## JWXT (教务系统)

1. Generate cookies locally: run the app once or use the Playwright refresh.
2. Export the cookie file:
   ```bash
   curl -X POST ... -d "{\"kind\":\"jwxt_cookies\", \"data\": $(cat data/jwxt_cookies.json)}"
   ```
3. The Render deployment will use these cookies for schedule sync.

## Chaoxing (超星学习通)

1. Generate state locally: `python scripts/refresh_chaoxing_state.py`.
2. Upload via the admin import API.
3. Set `CHAOXING_MOCK=false` in Render env.

## Health check

`GET /api/web/status` (requires Web UI session) includes a `data_dir` block:

```json
{
  "data_dir": {
    "configured": true,
    "path": "/var/data/cognitive-os",
    "exists": true,
    "writable": true,
    "jwxt_cookie_exists": true,
    "chaoxing_state_exists": true,
    "google_token_exists": true
  }
}
```

All values are booleans — no file content is exposed.

## Phone access

Open `https://cognitive-os.onrender.com` in any mobile browser.
Log in with the Web UI PIN.  Dashboard, schedule, and tasks are
served from the Render cloud, not your local machine.

## Security

- Never commit `.env`, `data/`, credentials, tokens, cookies, or state files.
- The admin import endpoint is **disabled by default** and requires a strong
  token in the `X-Admin-Token` header.
- All health-check fields are booleans — file contents are never echoed.
- If a token or cookie is compromised, regenerate it locally and re-import.
- Protect your Render account and the `RENDER_ADMIN_IMPORT_TOKEN`.
